# Pramaan

Pramaan is an in-progress Ethereum release-integrity and signing-safety project. Its intended chain joins reproducible security evidence, a signed release manifest, ENS release records and independent verification. A matching release is not an audit or a guarantee of safety; a scanner finding is a candidate until reproduced.

The currently runnable local slice is the public transaction decoder and web interface. Project management, release publishing, monitoring and the full demo are not yet integrated. See [RUN.md](RUN.md) for verified commands and [implementation status](docs/IMPLEMENTATION_STATUS.md) for test evidence and blockers. The intended backend API in [API_CONTRACT.md](docs/API_CONTRACT.md) is not yet fully implemented.

This repository includes pre-event work. The team's From Scratch eligibility for using it is unresolved; see [ETHGlobal rules](https://ethglobal.com/rules) and the status document.
